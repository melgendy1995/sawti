# P1.7 — Speak screen

The speak route is a fixed CSS grid, a cell, a sentence strip, and board links.
It depends on the P1.1 board document and does not write through the P1.2
repositories. The demo boards are in memory so the page works before the
caregiver gate (P1.10).

**M0 is not passed.** This screen does not change that.

## What you see

Open `/` or `/speak`. The home board is the v1.0 food example (`مية` at
document column 0) plus a few demo cells: a long label, a mixed
Arabic/Latin/digit label, a hidden cell, a link to a second board, and a
parked cell. The parked cell is not on the grid. The hidden cell keeps an
empty slot.

The Egyptian P0.3 sentence stays on the page (`data-testid="test-sentence"`),
and the footer still links to `/audio`, `/audio/diagnostics`, `/storage`, and
`/voice`.

## Modes

- **نطق مباشر** (speak-on-tap, the default). A valid activation speaks that
  cell at once. The strip does not grow.
- **جملة** (sentence mode). A valid activation appends the cell. **انطق**
  speaks the sequence. **احذف الأخير** drops the last word. **امسح** clears
  the strip. Speaking an empty strip does nothing.

`SentenceStore` is a signal in memory. It is not written to Dexie,
localStorage, or a file. Switching modes does not clear it.

A cell with `linkBoardId` opens that board. It is not spoken and not appended.
The demo drinks board links back to the food board.

Spoken text is `cell.spoken` when that string is non-blank, otherwise
`cell.label`. The strip shows the label.

## Where a cell sits

The grid has `board.rows` by `board.cols` tracks. Each slot sets `grid-row`
and `grid-column` from the document. DOM order is not the layout.

The grid element is `direction: ltr`, so CSS column 1 is the physical left.
For the default RTL board, document column 0 maps to CSS column `cols`
(the physical right). An LTR board would map column 0 to CSS column 1.
That mapping is a board fact. There is no language switch on this screen
(English UI is B-06).

Resizing the window does not change those inline `grid-row` / `grid-column`
values. A hidden cell uses the same placement and has no button.

Labels are in `<bdi>`. A symbol, when present, is the symbol key as text.
There are no ARASAAC images (P1.5) and no CDN requests.

## Pointer filters

`core/access` holds `PointerAccessFilter`.

- **Hold.** The pointer must stay down for `holdMs`. Releasing early, or
  cancelling, does not count.
- **Press vs release.** `release` (the default) accepts on pointer-up after
  the hold. `press` accepts when the hold elapses while the pointer is still
  down, and the later pointer-up does not accept again.
- **Debounce.** An accept closer than `debounceMs` to the previous accept is
  ignored.

Defaults are `holdMs: 0`, `debounceMs: 0`, `activation: 'release'`. The
settings screen that edits these is P1.10. Tests drive the filter with fake
timers (`Date.now` and `setTimeout`).

## What this does not do

- **P1.8** — recording → clip → device TTS → large text, and the diagnostics
  that go with that chain. P1.7 calls `CELL_SPEAKER`. The default
  `MemoryCellSpeaker` records the call and plays nothing.
- **P1.9** — the caregiver editor (add, move, hide, resize, photos).
- **P1.10** — the caregiver gate and profile settings, including the hold and
  debounce controls.
- **P1.5** — symbol art.
- **B-04** — scanning. **B-18** — swap. **B-06** — English UI.

Dexie is not imported by the speak route. The initial and speak bundle
budgets are unchanged (`250/300` kB initial, `120/150` kB speak).
