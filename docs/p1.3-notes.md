# P1.3 — Egyptian core vocabulary (AI draft)

This list is an **AI draft**. Native-speaker review and SLP sign-off are **pending**. Nothing here is marked approved. `reviewStatus` is `ai-draft` on the file and on every item.

Review table: [`docs/p1.3-core-vocab-review.csv`](p1.3-core-vocab-review.csv)

Source of truth: `content/vocab/ar-eg-core.yaml` (`dialect: ar-EG`). The runtime copy is `app/public/vocab/ar-eg-core.json`. The speak screen fetches that file. It is not imported into the initial bundle or the speak chunk. The service worker precaches `/vocab/*.json`.

## What is in the list

401 `vocabKey`s. Everyday Egyptian spellings (`مية` is stored as `ميّة`, `عايز` / `عايزة`, `أيوه` / `لأ`, `عربيّة`, `دلوقتي`). The 50 keys in `content/voice-spike/words.json` keep those spellings so later pack clips still match.

`display` is what the child sees. `speak` is what TTS should read. In this draft they are the same string. `ssml` is allowed by the schema and omitted on every item.

Categories: `person`, `verb`, `descriptor`, `noun`, `social`, `function`, `question`. Fitzgerald colors use the `fitz-*` names (`fitz-person`, `fitz-verb`, `fitz-descriptor`, `fitz-noun`, `fitz-social`, `fitz-function`, `fitz-question`).

Each item has one board slot. `water` is on the food board at row 0, col 0, color `fitz-noun`. The quick board's word cells are `want`, `hungry`, `tired`, `happy`, `sad`, and fourteen other keys. Those cells store a `vocabKey` and an empty label.

## Gender

The profile row field `gender` is `m` or `f` (`ProfileDirectory.genderOf`). When the speak screen opens, it reads the active profile and calls `BoardSession.setGender`. Until a profile loads, the default is `m`.

`BoardSession.board()` copies a core cell's `display` and `speak` for that gender when the stored label is empty. Quick-phrase labels therefore change with the profile. Cells that already have a label, including the P1.7 fixture (`مية`, the hidden cell, the parked cell, the drinks link), are not rewritten.

Navigation uses `linkBoardId` (home category links, and `الرئيسية` back to `home`). New word cells use `{ kind: "tts" }`. The food `water` cell reuses the existing symbol ref `arasaac` / `2248`.

## Extra fields

No extra item fields. The document adds `schemaVersion`, `dialect`, `reviewStatus`, `gloss_en`, `agreement`, and `board` / `row` / `col` so a slot and the draft status are part of the schema.
