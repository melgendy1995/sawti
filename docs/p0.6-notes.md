# P0.6 notes — iOS storage soak

Plan §6 P0.6, decision 14 / ADR-02, risks R-02. See `docs/adr/ADR-02-mediastore-ios-blobs.md` and `docs/p0.6-device-checklist.md`.

## What this is

A device-only spike to decide where media blobs live on an iOS Home Screen PWA: IndexedDB blobs (the default) or OPFS (the fallback). The `/storage` page writes ~200 MB with stored SHA-256 hashes, logs `persist()`/`estimate()`, and verifies the hashes after a reboot and after 14 days without rewriting. The same flow runs against both backends.

## How to run

```
cd app
npx ng serve --host 0.0.0.0 --port 4200 --ssl
```

Open `https://<LAN-IP>:4200/storage` on the phone (find the IP with `ipconfig getifaddr en0`), accept the self-signed cert, Add to Home Screen, open from the icon. Stop the server with Ctrl+C — do not leave it running. Full device steps are in `docs/p0.6-device-checklist.md`.

The page is also reachable from the speak page ("التخزين" link).

## Key points

- **200 MB is generated on the device at runtime** (20 × 10 MiB deterministic xorshift chunks). Nothing large is committed. The bytes are patterned, not media of any person.
- **Both backends are present**: `IndexedDbMediaStore` (`backend: 'idb'`, blobs stored directly in IndexedDB) and `OpfsMediaStore` (`backend: 'opfs'`, one file per key under a private directory). Picked in the UI.
- **Results persist across reload.** A `manifest.json` key stores the hashes, so "Load existing" + "Verify" work after a reboot and after 14 days with no rewrite.
- **QuotaExceededError is shown, not thrown.** The write stops and keeps what it got; the report captures how far it got. Do not retry on a low-disk phone.
- **Memory stays bounded:** one chunk buffer is built, written, and dropped before the next.
- Lazy route, so initial/speak bundle budgets are unaffected (storage is its own ~24 kB chunk).

## Unit tests (CI)

`npm test` covers only pure logic on tiny fixtures: SHA-256 against FIPS vectors, report/verify summary shape, deterministic chunks, and the self-test write→read→compare path with an in-memory fake store. jsdom has no IndexedDB and no OPFS and never writes 200 MB.
