## Voices (verified, not chosen)

Microsoft's [language and voice support](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts) table lists two standard `ar-EG` neural voices: `ar-EG-SalmaNeural` (female) and `ar-EG-ShakirNeural` (male). Checked 2026-11-05. This spike compares them. It does not pick one. §2.9's later female default is still a human decision.

Azure Speech Free (F0) includes 0.5 million neural characters per month ([pricing](https://azure.microsoft.com/en-in/pricing/details/cognitive-services/speech-services/)). Real-time TTS on F0 is 20 transactions per 60 seconds ([quotas](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/speech-services-quotas-and-limits)). The script's default pause is 3100 ms so a free resource stays under that cap. A paid tier can pass `--min-interval-ms 750` (~1.3 requests/second). HTTP 429 is retried up to 5 times with backoff, honoring `Retry-After`. Each wait is capped at 60 seconds. Any other HTTP error stops the run. Each request aborts after 30 seconds.

## Dry-run (no key, no network)

From the repo root:

```bash
node scripts/voice-spike/render.mjs --dry-run
```

Prints 200 tab-separated lines (`key`, `gender`, `voice`, `text`, `hit` or `miss`) and a summary, then exits 0. `--dry-run` does not read `.env`. If you omit `--dry-run` and `AZURE_SPEECH_KEY` is unset, the script prints the same manifest and does not call the network.

CI runs `node --test scripts/voice-spike/render.test.mjs` only. It does not run a real render and does not download clips. This session did not call Azure.

## Real render (Mahmoud, after P0.1)

1. Read the Azure Speech terms. Do not synthesize if they forbid storing or redistributing the audio. The script cannot check that.
2. Copy `.env.example` to `.env` (gitignored). Set `AZURE_SPEECH_KEY` and `AZURE_SPEECH_REGION` (for example `eastus`). Optional `FFMPEG_PATH`. Process environment wins over the file. The values are never written to the log or the repo.
3. ffmpeg must be executable. On this Mac that is `/opt/homebrew/bin/ffmpeg`. If it is missing, the script stops before any request and prints that path.
4. From the repo root: `node scripts/voice-spike/render.mjs`

The script POSTs SSML (`xml:lang="ar-EG"`) to `https://{region}.tts.speech.microsoft.com/cognitiveservices/v1` with `Ocp-Apim-Subscription-Key`, `Content-Type: application/ssml+xml`, and `X-Microsoft-OutputFormat: audio-24khz-48kbitrate-mono-mp3`. Spoken text is XML-escaped.

ffmpeg then applies `silenceremove` plus `loudnorm` and writes mono MP3, 24 kHz, 48 kbps (`libmp3lame`), the same profile as the P0.4 tones. Files land in `app/public/voice-spike/{key}.{gender}.{voice}.mp3`.

Cache: `scripts/voice-spike/out/cache.json` stores a SHA-256 of `(text, voice, output format, ssml)` and the filename. A hit (hash present and the MP3 still on disk) spends 0 characters and makes no request. The cache file has no audio and no key. Both the cache directory and the MP3s are gitignored. Do not commit them.

## Rating page

`/voice` is lazy, so the speak budget stays on the speak chunk. This production build (`base href /`): initial **237.88 kB** raw (transfer 65.53 kB; warning 250 / error 300), speak chunk **2.16 kB** raw (warning 120 / error 150), voice chunk **17.67 kB** raw. No budget warning was printed. `ngsw.json` from this build has no `voice-spike` URL. `ngsw-config.json` was not edited.

The page is an anonymous local form, not a live survey. The banner says ratings wait for the published P0.10 notice (or, if it slips, adult volunteers who are not pilot families). There is no field for a name, age, photo, recording, school, or medical note. Optional role: `parent`, `SLP`, `adult volunteer`, `other`. Scores are 1–5 for Salma and 1–5 for Shakir. The page shows both numbers and does not declare a v1.0 voice.

Playback uses one `Audio` element started from a click. The sample is 10 keys (want, hungry, tired, happy, sad, cold, water, bathroom, no, friend), each gender, both voices. "Play all available" walks that set and skips missing files. If the probe clip is missing, the page explains `--dry-run`, the real render, and copying MP3s into `app/public/voice-spike/`.

The draft is `localStorage` key `sawti.voice-spike.draft.v1`. Copy report writes an ISO timestamp, `userAgent`, role, both scores, the optional comment, and the clip filenames that started playing. Paste that text into notes later. Nothing is submitted.
