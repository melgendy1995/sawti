# P1.8 device checklist — speak fallback

Feel-test on a phone. The Mac serves this worktree. Stop the server when you finish (Ctrl+C). Do not leave it running.

Do not kill `caffeinate`. Do not kill an `ng serve` that is already running for another checkout. Port 4200 may already be taken by the main checkout. Use 4201.

This pass does **not** certify p95 ≤ 150 ms. That number is a human measurement on a D2-class phone (pointer-up until sound, or until the no-voice banner). CI cannot measure it. Write the result in the notes you keep for M0. Do not treat a green unit test as that measurement.

**M0 is not passed.**

## Serve

1. على الماك، من طرفية جديدة، من مجلد التطبيق في فرع `p1.8-audio-service`:

   On the Mac, in a new terminal, from this worktree's app folder:

   ```
   cd /Users/mahmoudelgendy/Documents/Files/projects/sawti-p1.8/app
   npx ng serve --host 0.0.0.0 --port 4201
   ```

2. عنوان الماك على الشبكة (يتغيّر):

   LAN IP (it can change):

   ```
   ipconfig getifaddr en0
   ```

3. من الهاتف، نفس الواي فاي، افتح:

   On the phone, same Wi-Fi, open:

   `http://<LAN-IP>:4201/`

   مثال / example: `http://192.168.1.20:4201/`

## Check

1. الصفحة تفتح على لوحة الكلام. جملة الاختبار المصرية ما زالت ظاهرة (`data-testid="test-sentence"`). روابط التذييل: تجربة الصوت، تشخيص الصوت، التخزين، تقييم الصوت.

   The speak board opens. The Egyptian test sentence is still there. Footer links: audio spike, diagnostics, storage, voice rating.

2. الوضع «نطق مباشر». اضغط «مية». يفترض أن تسمع صوت الجهاز العربي إن وُجد (`ar-EG` ثم `ar-SA` ثم أي `ar-*`). اللهجة غير مضمونة. إن لم يوجد صوت عربي، يظهر الشريط «لا يوجد صوت» ونص الخلية بخط كبير. لا مسار صامت.

   Speak-on-tap. Tap «مية». You should hear the device's best Arabic voice if one is installed. The dialect is not guaranteed. If none is installed, the banner «لا يوجد صوت» appears and the cell text is shown large. No path may stay silent.

3. الوضع «جملة». أضف كلمتين ثم «انطق». الكلمات تُنطق بالترتيب، أو يظهر الشريط للكلمة التي بلا صوت.

   Sentence mode. Add two words, then «انطق». They play in order, or the banner names the words that had no audio.

4. افتح «تشخيص الصوت». قسم حالة السلسلة يظهر: هل النطق الآلي متاح، اسم الصوت المختار أو «لا يوجد صوت عربي»، آخر مصدر (`recording` / `pack` / `tts` / `text`)، عدد الأصوات، ونوع جلسة الصوت.

   Open diagnostics. The chain block shows TTS availability, the selected voice or «لا يوجد صوت عربي», the last source, the voice count, and the audio session type.

5. مقياس الثلاثين ضغطة لم يتغيّر. p95 هنا ليس حكم M0.

   The thirty-tap meter is unchanged. Its p95 is not the M0 verdict.

6. لا تسجيلات وليّ ولا مقاطع حزم بعد. المصدر المتوقع اليوم هو نطق الجهاز أو الشريط.

   There are no caregiver recordings and no pack clips yet. Expect device TTS or the banner.

7. أوقف `ng serve` قبل أن تغلق الطرفية.

   Stop `ng serve` before you close the terminal.
