# P0.3 app skeleton

Sawti (صوتي) shell: zoneless Angular PWA, Capacitor Android, RTL, self-hosted Arabic fonts, Cloudflare Pages build. Nothing here is deployed.

## Versions

| Piece | Value |
|---|---|
| Angular | `@angular/core` **22.2.4**, CLI **22.2.6**. Standalone, zoneless (`provideZonelessChangeDetection` in `app/src/app/app.config.ts`). No `zone.js`. |
| Capacitor | **8.6.0** (`@capacitor/core`, `@capacitor/cli`, `@capacitor/android`) |
| Android | `applicationId` / namespace **`app.sawti`** (placeholder until Q3). **minSdk 29** (Android 10+, Q6). **compileSdk 36**, **targetSdk 36** (Capacitor 8 template; platform `android-36` is installed). AGP **8.13.0**, Gradle wrapper **8.14.3**. App name **Sawti**. |
| Web output | `app/dist/sawti/browser` (`webDir` in `app/capacitor.config.ts`) |

`npx cap sync android` was run from `app/` after `cap add android`. It copied the web build into `android/app/src/main/assets/public` and wrote `capacitor.config.json`. Both paths are gitignored by `app/android/.gitignore`. No signing keystore was created.

Gradle itself does not run inside `cap sync`. A later `./gradlew :app:tasks` check:

- `JAVA_HOME=/opt/homebrew/opt/openjdk` is Homebrew OpenJDK **26.0.2**. Gradle 8.14.3 fails with `Unsupported class file major version 70`.
- The same task succeeds with Homebrew OpenJDK **21.0.12**: `JAVA_HOME=/opt/homebrew/opt/openjdk@21`. Use that JDK for any Gradle command until the wrapper understands JDK 26. `ANDROID_HOME=/opt/homebrew/share/android-commandlinetools`.

## How to run

```bash
cd app
npm ci
npm start          # ng serve at http://127.0.0.1:4200/  (base href /)
npm test           # Vitest via ng test. Do not pass --browsers=ChromeHeadless.
npm run lint       # ng lint
npm run stylelint  # src/**/*.{css,scss} only
npm run build      # production, base href /app/, budgets on
```

Pages output (no deploy):

```bash
scripts/build-pages.sh
# writes dist/pages/ (site at /, Angular browser build at dist/pages/app/)
```

`dist/` is gitignored. Optional `wrangler.toml` only sets `pages_build_output_dir = "dist/pages"`. No Cloudflare token, no `wrangler pages deploy`.

Android, after a web build, from `app/` with JDK 21:

```bash
export ANDROID_HOME=/opt/homebrew/share/android-commandlinetools
export JAVA_HOME=/opt/homebrew/opt/openjdk@21
npx cap sync android
```

Do not run `npx cap run` from this skeleton task. Debug install is a device check for later.

## CSP

Source of truth: `site/_headers`, copied to `dist/pages/_headers`.

On `/app/*`:

- `script-src 'self'` only. No inline scripts. Production sets `optimization.styles.inlineCritical` to **false**, because Angular's critical-CSS pass (Beasties) injects a `<script>` that rewrites stylesheet `media`. That script cannot carry a hash that stays valid across builds, and static Pages has no per-request nonce.
- `style-src 'self' 'unsafe-inline'`. **Exception.** Component styles are inserted as `<style>` elements at runtime. Headless Chrome, with that keyword removed, still painted the shell from the external stylesheet and then logged two violations: `Applying inline style violates the following Content Security Policy directive 'style-src 'self''` (two different sha256 hashes, one per component style). A static nonce is not available on Pages, so styles keep `'unsafe-inline'` and scripts do not.
- `connect-src 'self'`; `font-src 'self'`; `img-src 'self' data: blob:`; `worker-src 'self' blob:`; `object-src 'none'`; `base-uri 'self'`; `frame-ancestors 'none'`; `default-src 'self'`.
- `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-Frame-Options: DENY`.

**Trusted Types are not enabled.** Adding `require-trusted-types-for 'script'` (and `trusted-types angular angular#unsafe-bypass`, which is the policy Angular creates) does not fail `ng build`, but Chrome blocks service-worker registration: `This document requires 'TrustedScriptURL' assignment` and Angular `NG05604`. `@angular/service-worker` 22.2.4 calls `navigator.serviceWorker.register(script)` with a plain string. The shell still renders; the worker does not. With the CSP as committed (no Trusted Types), headless Chrome registered `ngsw-worker.js` at scope `/app/`, loaded both woff2 files, and showed the Egyptian sentence with `font-family` IBM Plex Sans Arabic.

Cache-Control is not stacked on the same URL. Pages joins repeated header names with a comma, so a broad `/app/*.js` immutable rule cannot also set `no-cache` on the worker. Hashed bundles are matched by prefix: `/app/main-*`, `/app/chunk-*`, `/app/styles-*`, `/app/polyfills-*` (`public, max-age=31536000, immutable`). `no-cache` is set on `/app/index.html`, `/app/ngsw.json`, `/app/ngsw-worker.js`, `/app/safety-worker.js`, and `/app/worker-basic.min.js`.

## Browserslist

`app/.browserslistrc` stays pinned: Safari/iOS >= 16.4, Chrome/ChromeAndroid/Android >= 80. `ng build` warns, and the pins stay:

```
One or more browsers which are configured in the project's Browserslist configuration fall outside Angular's browser support for this version.
Unsupported browsers:
android 157, chrome 118, … chrome 80, ios_saf 16.6-16.7, ios_saf 16.5, ios_saf 16.4, safari 16.6, safari 16.5, safari 16.4
```

Angular 22's own support floor is newer than Android 10's practical WebView floor (Chrome 80) and newer than iOS 16.4. The pin is intentional (plan §3.1, Q6).

## Budgets and base href

Production `baseHref` is `/app/`. Development / `ng serve` keeps `<base href="/">`. Manifest `start_url` and `scope` are `./`, so they follow the manifest URL (`/app/` on Pages, `/` on ng serve).

Budgets (raw size, warning/error): initial **250 kB / 300 kB**, lazy bundle named `speak` **120 kB / 150 kB**. This production build: initial **202.77 kB** (transfer ~57 kB), speak **1.84 kB**.

`dist/pages/app/ngsw.json` lists `/app/…` shell files only. It has no `/packs/` URL. `ngsw-config.json` still precaches only the app shell, `/fonts/*.woff2`, and `/icons/*.png` (E5).

## Deviations

- **Capacitor and `/app/`.** The production build that `cap sync` copies has `<base href="/app/">`. The WebView serves `webDir` at `/`, so script and navigation URLs would be requested under `/app/` and miss. Pages is the path this base href is for (checked: `dist/pages/app/index.html` has `<base href="/app/">`, and Chrome loaded `/app/main-….js`). Before a debug APK install, add a build configuration with base href `/` and sync that output. Not done here because this task requires the production configuration to stay `/app/`.
- **style-src** and **Trusted Types**: see CSP above.
- **JDK 26 vs 21**: see Versions above.
- **Hashed-asset cache patterns** are prefix rules, not `/app/*.js`, so the unhashed service worker is not marked immutable. See CSP above.
- `api/.gitkeep` is an empty backlog marker. No API, Dexie, audio, editor, or sync code. No `features/goals/`.
- Capacitor's Android template still has a `google-services` classpath and example tests under `com.getcapacitor.myapp`. Nothing applies the Google services plugin, and no Google script is loaded.
- No third-party runtime hosts (no Google Fonts, analytics, Sentry, Turnstile). No telemetry. No secrets. No keystores.
