# P1.1 — Board domain model + INV-1 property tests

Pure-TS domain model for a Sawti board, with the INV-1 invariants from plan
v1.1 §5.2 pinned by unit tests and a 10k-run property test. Depends on P0.3
only. No Angular, Dexie or Capacitor here — that layering is enforced by
`app/eslint.config.js` (`no-restricted-imports` on `src/app/domain/**`).

## Where things live

- `content/schemas/board.schema.json` — JSON Schema, the source of truth for the
  board document shape.
- `content/fixtures/board/v1.0-example.json` — the plan §2.6 example (stable fake
  UUIDs). Validated against the schema and checked against the TS types in
  `board.schema.spec.ts`.
- `app/src/app/domain/board/`
  - `board.types.ts` — `BoardDoc`, `BoardCell`, `ParkedCell`, the `BoardOp`
    union, `BoardOpError`, grid-size bounds.
  - `board.ts` — `createBoard`, helpers, `applyOp` / `applyOpResult`.
  - `index.ts` — the public API.
  - `*.spec.ts` — unit, schema and property tests.

The TS types are hand-written to mirror the schema; `board.schema.spec.ts`
keeps the two honest (the fixture must validate and be assignable to `BoardDoc`,
and unknown fields must be allowed at both levels). No codegen step is needed.

## Public API

From `@domain/board` (`src/app/domain/board`):

- `createBoard(input): BoardDoc` — build a valid, empty-by-default board. Throws
  `BoardOpError('invalid-grid-size')` for a grid outside `1..12`. Preserves
  unknown keys on the input.
- `getCell(board, id): BoardCell | undefined` — a grid (non-parked) cell by id.
- `isParked(board, id): boolean` — whether an id names a parked cell.
- `occupantAt(board, row, col): string | null` — id occupying a slot, if any.
- `inBounds(rows, cols, row, col): boolean` — slot-in-grid test.
- `applyOpResult(board, op): ApplyResult` — apply one op, returning
  `{ ok: true, board }` or `{ ok: false, error: BoardOpError }`.
- `applyOp(board, op): BoardDoc` — total reducer form: a refused op returns the
  board unchanged (reference-identical). Property tests fold with this.

All functions are pure and return a new board; inputs are never mutated.
Unknown keys at the board and cell level are copied through every op.

## Operations (`BoardOp`)

Only `move` may change a position, and only for the cell it names (plan §5.2,
errata E6).

| Op | Changes position? | Notes |
|----|-------------------|-------|
| `upsert` | No | Updates an existing cell's fields in place (grid or parked). A *new* cell needs an empty, in-bounds slot; occupied → `occupied-slot`, off-grid → `out-of-bounds`, no row/col → `missing-position`. |
| `hide` / `unhide` | No | Toggles `hidden`; the slot stays. Unknown id → `unknown-cell`. |
| `resize` | No (parks) | Sets `rows`/`cols` (guard `1..12` → `invalid-grid-size`). Cells outside the new bounds move to `parked`, keeping id + last row/col. No cell is deleted. Growing back does **not** auto-unpark. |
| `move` | **Yes** | Moves the named cell to an empty in-bounds slot. A parked cell may be moved back this way (explicit, not auto-restore). Occupied → `occupied-slot`, off-grid → `out-of-bounds`, unknown id → `unknown-cell`. |
| `packUpdate` | No | Updates pack-facing fields (`symbol`, `audio`, `vocabKey`, `color`) without moving the cell. |
| `backupImport` | No | Merges cell content + unknown fields by id. Existing cells keep their position; new ids go to an empty slot else to `parked`. The domain op behind a backup restore — zip parsing is P1.11, not here. |

`rev` is the only concurrency token (per-cell `rev` was removed in v1.1). A
successful mutating op bumps `rev` by 1; a refused op leaves the board (and
`rev`) unchanged. `backupImport` with no cells is a no-op and does not bump.

Grid size is capped at **12×12** (`MAX_GRID_SIZE`), minimum 1×1. 12 covers every
grid size in the plan's layouts with headroom.

## INV-1 properties (§5.2)

Pinned as unit tests in `board.spec.ts` and as fast-check properties in
`board.property.spec.ts` at **`{ numRuns: 10_000 }`**:

1. **Position stability** — after any sequence of non-move ops (upsert, hide,
   unhide, resize, packUpdate, backupImport), a cell still present and not parked
   sits at the exact `[row, col]` it started at.
2. **No deletion** — every original cell id survives; resize parks rather than
   deletes, and growing back leaves parked cells parked.
3. **Hide keeps the slot** — hidden cells do not move or vacate.
4. **Move refusal** — a move onto an occupied or out-of-bounds slot is refused
   and the source cell stays put.
5. **Unknown-field preservation** — board- and cell-level unknown keys survive
   every op.
6. **Move scope** — a single `move` changes at most the named cell's position;
   every other cell holds, or the move was refused and the board is unchanged.

## Running the tests

From `app/`:

```sh
npm test                 # all specs (default **/*.spec.ts), incl. 10k-run props
npm run lint
npm run stylelint
npm run build

# domain coverage (text + html report, 90% lines threshold on src/app/domain/**)
npx ng test --configuration coverage --include "**/domain/**/*.spec.ts" --watch=false
```

Latest domain coverage: 100% lines / 100% statements / 100% functions /
97.82% branches on `board.ts`, over the §5.1 ≥90% target.

## Scope notes

- **`swap` is B-18** — deliberately not implemented. It arrives later under the
  same rule as `move` (changes only the two cells it names).
- Sync resolution ops arrive with **B-25**.
- **P1.2 is next**: Dexie persistence, repositories, NativeMediaStore. None of
  that is here — `domain/` stays pure TS.
