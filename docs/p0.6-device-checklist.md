# P0.6 device checklist — iOS storage soak

Run this on **two iPhones** (label them P1 and P2). The Mac serves the app. Stop the server when you finish (Ctrl+C). Do not leave it running.

The 200 MB is generated on the phone at runtime. It is patterned random bytes, not media of any person. Paste results into `docs/adr/ADR-02-mediastore-ios-blobs.md`, section **Device results**.

HTTPS matters: Add to Home Screen, `persist()`, and the service worker all want it. Plain HTTP is only a fallback for a quick Safari-tab check.

## Serve — التشغيل

1. على الماك، من الطرفية (HTTPS):

   On the Mac, in a terminal (HTTPS):

   ```
   cd /Users/mahmoudelgendy/Documents/Files/projects/sawti/app
   npx ng serve --host 0.0.0.0 --port 4200 --ssl
   ```

   بديل سريع لتبويب سفاري فقط (بدون تثبيت/persist): `npx ng serve --host 0.0.0.0 --port 4200`.

   Quick Safari-tab-only fallback (no install / no persist): `npx ng serve --host 0.0.0.0 --port 4200`.

2. عنوان الماك على الشبكة (يتغيّر). مثال سابق على هذه الشبكة: `192.168.1.20`.

   LAN IP (it can change). An earlier address on this network was `192.168.1.20`.

   ```
   ipconfig getifaddr en0
   ```

3. من كل آيفون، نفس الواي فاي، افتح `https://<LAN-IP>:4200/storage` واقبل تحذير الشهادة الذاتية.

   On each iPhone, same Wi-Fi, open `https://<LAN-IP>:4200/storage` and accept the self-signed warning.

   مثال / example: `https://192.168.1.20:4200/storage`

4. Tailscale غير مثبّت هنا. إن ثبّته لاحقاً فالعنوان ناتج `tailscale ip -4`. ليس مطلوباً الآن.

   Tailscale is not installed. If you install it later, the address is the output of `tailscale ip -4`. Not required now.

5. عند الانتهاء: Ctrl+C في طرفية `ng serve`. لا تترك الخادم شغّالاً.

   When finished: Ctrl+C in the `ng serve` terminal. Do not leave the server running.

## Add to Home Screen — التثبيت

6. على **كل** آيفون: في سفاري افتح الصفحة ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية». ثم افتح التطبيق **من الأيقونة** (وضع standalone)، وليس من تبويب سفاري.

   On **each** iPhone: in Safari open the page → Share → **Add to Home Screen**. Then open the app **from the icon** (standalone), not from a Safari tab.

   تبويب سفاري وتطبيق الشاشة الرئيسية **لا** يتشاركان التخزين. لا بد أن تفتح من الأيقونة.

   A Safari tab and the Home Screen app do **not** share storage. You must open from the icon.

## Steps — الخطوات (run per phone, for each backend)

7. اطلب الثبات: اضغط **persist()** ثم **اقرأ الحالة**. انسخ التقرير (زر «انسخ التقرير»).

   Request durable storage: tap **persist()**, then **read state**. Copy the report (Copy report button).

8. اختر الواجهة الخلفية **IndexedDB**. اضغط **فحص ذاتي** (بضعة كيلوبايت) للتأكد أن الواجهة تعمل.

   Select the **IndexedDB** backend. Tap **Self-test** (a few KB) to confirm the backend works.

9. اضغط **اكتب ~200 م.ب**. انتظر حتى يكتمل الشريط. اضغط **تحقّق** فوراً. يجب أن يكون الحكم «نجح التحقق». انسخ التقرير والصقه في ADR-02.

   Tap **Write ~200 MB**. Wait for the bar to finish. Tap **Verify** immediately. The verdict must be "Verify passed". Copy the report into ADR-02.

10. أعد تشغيل الهاتف. افتح التطبيق **من الأيقونة** (ليس تبويب سفاري). اضغط **حمِّل المحفوظ** ثم **تحقّق**. لا تكتب من جديد. يجب أن تتطابق كل القطع. انسخ التقرير.

    Reboot the phone. Open the app **from the icon** (not a Safari tab). Tap **Load existing**, then **Verify**. Do **not** rewrite. All chunks must match. Copy the report.

11. اترك التطبيق **بدون فتح لمدة 14 يوماً**. بعدها افتح من الأيقونة، **حمِّل المحفوظ** ثم **تحقّق** (بدون كتابة). انسخ التقرير.

    Leave the app **unopened for 14 days**. Then open from the icon, **Load existing**, then **Verify** (no write). Copy the report.

12. كرّر الخطوات 8–11 للواجهة **OPFS** على نفس الهاتفين. وضّح في التقرير أن `backend: opfs` (التقرير يسجّلها تلقائياً).

    Repeat steps 8–11 for the **OPFS** backend on the same phones. The report records `backend: opfs` automatically, so each paste is clearly labeled.

13. حذف الأيقونة (على هاتف واحد يكفي، بعد كتابة+تحقق ناجح): احذف أيقونة الشاشة الرئيسية، ثم أعد إضافة الـ PWA، افتح `/storage`، اضغط **حمِّل المحفوظ**. يجب أن يظهر «لا يوجد ملف محفوظ» — أي أن البيانات اختفت. سجّل النتيجة في ADR-02.

    Icon deletion (one phone is enough, after a successful write+verify): delete the Home Screen icon, re-add the PWA, open `/storage`, tap **Load existing**. It should report "no manifest found" — the data is gone. Record this in ADR-02.

## Low disk — المساحة ممتلئة

14. إن ظهر خطأ «توقّفت الكتابة بسبب امتلاء المساحة» (QuotaExceeded)، **لا تُعد المحاولة**. انسخ هذا التقرير كما هو والصقه؛ إعادة المحاولة قد تُعطّل الهاتف.

    If you see "Write stopped on quota" (QuotaExceeded), **do not retry**. Copy that report as-is and paste it; retrying can brick a low-disk phone.

## Where to paste — أين تلصق

15. كل التقارير وصفوف الجداول تذهب إلى `docs/adr/ADR-02-mediastore-ios-blobs.md` تحت **Device results** (جداول persist، وIndexedDB، وOPFS، وحقائق التخزين، وحذف الأيقونة، وإصدارات iOS).

    All reports and table rows go into `docs/adr/ADR-02-mediastore-ios-blobs.md` under **Device results** (persist, IndexedDB, OPFS, storage facts, icon deletion, iOS versions).
