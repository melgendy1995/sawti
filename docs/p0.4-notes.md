# P0.4 audio spike

In-browser spike on the P0.3 shell. Twenty generated tones, unlock, decode when `/audio` opens, diagnostics meter. Not deployed. `npx cap sync` / `npx cap run` were not run, so `app/android/.../assets/public` does not contain this route yet.

| Piece | Value |
|---|---|
| Angular | `@angular/core` **22.2.4**, CLI **22.2.6**. Same zoneless standalone app as P0.3. |
| ffmpeg | **9.0** at `/opt/homebrew/bin/ffmpeg` (libmp3lame). Used only to generate files on this Mac. |

Capacitor and the Android Gradle pin are unchanged from `docs/p0.3-notes.md`.

## Clips

`app/public/spike-clips/01.mp3` … `20.mp3`. Sine tones, not Azure and not speech. Labels on the grid are Arabic display text only (ماء، أكل، مدرسة، …).

Each file: mono MP3, duration **0.350 s**, lame stream bitrate **48 kbps**, sample rate **24 kHz**. `ffprobe` format bitrate is about **61 kbps** because a 0.35 s file's container overhead dominates; the encoder setting is `-b:a 48k`. Frequencies in order, Hz: 220, 247, 262, 294, 330, 349, 392, 440, 494, 523, 587, 659, 698, 784, 880, 988, 1047, 1175, 1319, 1568. Short fades (10 ms in, 70 ms out) keep the tone from clicking.

Regenerate (no network):

```bash
cd /Users/mahmoudelgendy/Documents/Files/projects/sawti
freqs=(220 247 262 294 330 349 392 440 494 523 587 659 698 784 880 988 1047 1175 1319 1568)
i=1
for f in "${freqs[@]}"; do
  n=$(printf '%02d' "$i")
  /opt/homebrew/bin/ffmpeg -y -hide_banner -loglevel error \
    -f lavfi -i "sine=frequency=${f}:sample_rate=24000:duration=0.35" \
    -af "afade=t=in:st=0:d=0.01,afade=t=out:st=0.28:d=0.07" \
    -ac 1 -c:a libmp3lame -b:a 48k \
    "app/public/spike-clips/${n}.mp3"
  i=$((i+1))
done
```

URLs are `spike-clips/<file>` resolved against `<base href>` (`/` for `ng serve` and Capacitor, `/app/` for Pages). They are not under `/packs/`.

## Routes

| Path | Page |
|---|---|
| `/speak` | Unchanged Egyptian sentence, plus links to `/audio`, `/audio/diagnostics`, and `/storage`. |
| `/audio` | 20-cell board. Decode on open. `pointerup` plays the decoded buffer. |
| `/audio/diagnostics` | 30 taps, p50/p95, pass/fail at 150 ms, copyable report. |
| `/storage` | No route yet. The `**` redirect sends it to `/speak` until P0.6. |

Speak bundle this build: **2.06 kB** raw (budget warning 120 / error 150). Initial **229.61 kB** raw, transfer **63.40 kB** (warning 250 / error 300). P0.3 notes recorded initial 202.77 kB. Audio code is in lazy chunks (`audio` 4.38 kB, `diagnostics` 9.66 kB, shared engine chunk 9.34 kB), not in `main`. Budgets were not raised. No component-style budget warning was printed.

`app/dist/sawti/browser/ngsw.json` from this build lists the shell, fonts, icons, and the emitted `/*.js` chunks. It has no `/packs/` URL and no `spike-clips` URL. `ngsw-config.json` was not edited (E5). The MP3s are fetched when the board opens; the service worker does not precache them.

## Deviations

- Tones, not Azure neural voices and not the P1.8 fallback chain. No caregiver recordings, no native TTS.
- Sample rate is 24 kHz. The plan's production audio target cited here is 48 kbps mono; the spike follows that bitrate, not a 48 kHz clock.
- The app cannot read the iPhone silent switch. It sets `audioSession.type = 'playback'` when the API exists, and it requires an on-screen confirm ("أسمع الصوت" / "لا أسمع شيئاً"). CI does not prove the switch.
- Resume retry is `visibilitychange` and `pageshow` only. No Bluetooth listener.
- Spike MP3s are not added to the service worker. Offline after a first visit depends on the browser HTTP cache, not `ngsw`.
- `/storage` is a link only.
- Android assets were not refreshed (`cap sync` not run).
